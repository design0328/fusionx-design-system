Publishing System

Layout

The FusionX Layout System defines how brand, content, imagery, data, and technical information are composed across briefs, brochures, presentations, and other publishing formats. It turns recurring production patterns into a consistent, scalable visual language.

This first draft is derived from existing FusionX collateral, not designed fresh. It will evolve as patterns are reviewed against real InDesign briefs and presentation decks, standardized, and formally approved.

Draft · v0.1

Overview

Editorial

Briefs, brochures, one-pagers, and print collateral.

Presentations

Sales decks, executive presentations, investor materials, and technical storytelling.

Components

Reusable content structures such as metric cards, feature blocks, callouts, diagrams, tables, and CTAs.

Layout principles

One dominant idea

Every page or slide should have a clear primary message.

Hierarchy before decoration

Structure, reading order, and emphasis should guide visual decisions.

Repeatable, not repetitive

Patterns should create consistency while allowing appropriate variation.

Content determines density

Layout density should reflect the purpose and complexity of the information.

Page anatomy

Conceptual regions common to FusionX pages and slides — not exact templates, and not tied to specific measurements.

Editorial page anatomy

  1. Section label
  2. Primary headline
  3. Supporting narrative
  4. Visual or data region
  5. Footer and page number

Presentation slide anatomy

  1. Context label
  2. Slide headline
  3. Core message
  4. Supporting visual or proof
  5. Source or footer region

Status and governance

Every pattern in the library above carries one of four statuses. All initial patterns are provisional until the collateral audit is complete — treat "Candidate" and "Observed" as the working defaults, not "Approved."

Observed

Found in existing collateral but not yet standardized.

Candidate

Repeated across multiple pieces and being evaluated as a reusable standard.

Approved

Reviewed and accepted as an official FusionX publishing pattern.

Deprecated

No longer recommended for new work.
