Getting the fonts

Montserrat is synced via Adobe Fonts in the source InDesign file, not embedded locally — make sure it's activated in Creative Cloud before opening FusionX documents, or the file will substitute a placeholder font. Libre Franklin and JetBrains Mono are both locally embedded (variable font builds) and travel with the packaged InDesign file. All three are open-source and available on Google Fonts for web/HTML collateral and this site — though for InDesign work, match the exact style/weight names shown below rather than assuming Google's naming lines up one-to-one with Adobe Fonts' style list.
