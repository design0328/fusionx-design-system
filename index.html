Diamanti · FusionX Publishing System

A living design system for FusionX collateral.

This site is the single source of truth for FusionX's color, icon, and imagery language — built to evolve in place. Edit the source, push to GitHub, the site updates. Nothing here is final; it's a proposal for how we standardize going forward.

Why this exists

FusionX collateral — buyer briefs, solution briefs, decks, data sheets — was being produced piece by piece without a shared source of truth. That surfaced the same questions on every new document: which black? which blue? what kind of image belongs on a cover vs. a data sheet? This system answers those questions once instead of re-deciding them per document.

Nobody asked for a formal design system. The work of producing consistent collateral kept surfacing the need for one. Treat this as a starting proposal — flag anything that doesn't match how you're already working.

Brand architecture

Diamanti is the corporate brand and stays as-is. FusionX is the product/publishing language sitting underneath it — not a rebrand, a distinct system. The two color palettes are deliberately kept separate; don't cross-pollinate them even where a hex value happens to coincide.

Design philosophy

Enterprise-first, technical without being cold, modern minimalism, modular, scalable. Concretely: dark-mode-forward, restrained use of accent color, abstract/geometric imagery for decoration and real documentary photography only where credibility matters — never stock, never literal hardware rendered as art.

How to evolve this system

Everything on this site renders from the JSON files in /data. To change a color or update icon status, edit the JSON — every page referencing it updates automatically, no HTML editing required. To add a new page or section, follow the pattern in the existing HTML files. See the repo README.md for the full workflow, including local preview and publishing to GitHub Pages.
